# VendorMap Red Certificate

This folder contains the standalone LaTeX certificate for Darshan Gavate, Vivek Patil,
Sneha Tingare, and Kalyani Ugale.

Compile it with:

```powershell
xelatex -interaction=nonstopmode -halt-on-error certificate.tex
```

Edit the project title or academic year near the top of `certificate.tex`. The certificate
uses the local `kk-wagh-emblem.png` file so the folder remains self-contained.
