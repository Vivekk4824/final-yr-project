Problem Definition
PROJECT FINAL EXAMINATION




       - Municipal vendor records, zones and spatial evidence are

MCDA Recommendation Method
PROJECT FINAL EXAMINATION




                 Score(z) = SUM [ weight(i) x normalized factor(i,z) ]

         - Eligibility filters are applied before scoring.
         - Each factor contribution is shown to the user.
         - Missing values are handled without inventing evidence.
         - Officer approval is required before allocation.

Ranking Eligibility Rules
PROJECT FINAL EXAMINATION




       - Zone type must be FREE and analytically scoreable.
       - Live status and verified capacity must allow a request.
       - A selected division becomes a strict candidate filter.
       - The current zone is excluded during relocation.
       - Only eligible candidates enter MCDA ranking.

Final Score and Rank Order
PROJECT FINAL EXAMINATION




        Score = 100 x weighted available-factor sum / available weight

       - Each factor is normalized to a value from 0 to 1.
       - Missing factors are omitted and available weights are
       renormalized.
       - Factor contributions add to the final 0-100 score.
       - Candidates sort by score descending, then zone ID ascending.
       - The score supports comparison and is not a success probability.
