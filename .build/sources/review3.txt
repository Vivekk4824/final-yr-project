System Architecture — Brief Recap
   Collect and integrate vendor, zone,
   location, and contextual data.
   Process the data using geospatial analysis
   and recommendation techniques.
   Generate a suitability score for different
   vendor types across designated zones.
   Display the results through an interactive
   dashboard/map to support better vendor
   placement decisions.
