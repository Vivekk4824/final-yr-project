MCDA Recommendation Method
PROJECT FINAL EXAMINATION
Score(z) = SUM [ weight(i) x normalized factor(i,z) ]
- Eligibility filters are applied before scoring. - Each factor contribution is shown to the user. - Missing values are handled without inventing evidence. - Officer approval is required before allocation.

MCDA Parameters and Baseline Weights
PROJECT FINAL EXAMINATION
- Business compatibility - 25% - Commercial activity - 20% - Access - 20% - Facilities - 15% - Vendor preference - 10% - Historical evidence - 10%

Ranking Eligibility Rules
PROJECT FINAL EXAMINATION
- Zone type must be FREE and analytically scoreable. - Live status and verified capacity must allow a request. - A selected division becomes a strict candidate filter. - The current zone is excluded during relocation. - Only eligible candidates enter MCDA ranking.

Factor Scoring Parameters
PROJECT FINAL EXAMINATION
Counts use diminishing returns
- Commercial POIs scale: 12 - Markets scale: 4 - Food POIs scale: 8 - Historical evidence scale: 50

Distance and access transforms
- Major-road distance scale: 400 m - Bus-access distance scale: 1,000 m - Pedestrian density scale: 5,000 - Closer distances receive higher scores

Final Score and Rank Order
PROJECT FINAL EXAMINATION
Score = 100 x weighted available-factor sum / available weight
- Each factor is normalized to a value from 0 to 1. - Missing factors are omitted and available weights are renormalized. - Factor contributions add to the final 0-100 score. - Candidates sort by score descending, then zone ID ascending. - The score supports comparison and is not a success probability.
